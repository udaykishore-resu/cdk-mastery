# Module README template

Every module `README.md` follows this shape. Sections may be short but none may be empty.

```markdown
# NN · Title

> One-sentence promise: what you can do after this module that you could not before.

## Why this exists (the problem)
The pain that existed before this capability, in one or two paragraphs. Concrete, not abstract.

## Mental model
One analogy or diagram (mermaid) that a reader can hold in their head.

## How it works
The mechanics. Step by step. Reference the source files by path and quote the important lines.

## Walkthrough
What each file in `src/modules/NN-slug/` does, in the order to read them, and the command(s) to run.

## Production notes
What breaks at scale, what costs money, what is a security footgun, what to monitor.

## Gotchas
Bullet list. Each: symptom → cause → fix.

## Exercises
Three exercises, easy → hard. Solutions live in `src/modules/NN-slug/solutions/` (or inline under a
<details> block) so learners can self-test.

## Checklist
- [ ] Production checklist items specific to this module
- [ ] Code-review checklist items specific to this module

## Interview angle
Two or three questions a Staff/Principal interviewer would ask about this module, with a model answer outline.

## References
Official docs and source links used.
```
